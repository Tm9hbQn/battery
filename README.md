# Frictionless Battery Monitor

Frictionless Battery Monitor היא מערכת חדשנית לניטור סוללה מתקדם ורחב היקף לאנדרואיד. המערכת מספקת תובנות עמוקות על צריכת החשמל, מצבי מערכת, ואפליקציות ברקע – והכל **ללא צורך בחיבור כבל או למחשב**, באמצעות שימוש ב-Wireless Debugging ומנגנון Shizuku פנימי.

## תכונות עיקריות
* **גישה להרשאות עמוקות ללא מחשב**: שימוש ב-Shizuku (Wireless Debugging) לקבלת פקודות ADB מתקדמות.
* **מסד נתונים מקומי**: שמירת היסטוריית שימוש באמצעות SQLite למניעת אובדן נתונים בטעינה מלאה.
* **גיבוי וסנכרון חכם**: סנכרון נתונים אנונימי מול Supabase ליצירת מאגר ידע (Big Data) על דפוסי פריקה לכל דגם מכשיר.
* **חיזוי מתקדם ופתרון "ההתחלה הקרה"**: משיכת Baseline מהענן ושילוב מודל ML מקומי למתן תחזיות פריקה אישיות ומדויקות מרגע ההתקנה.
* **ניתוח מקיף**: ניטור Wakelocks, תדרי מעבד, חומרת רשת, זרם, מתח, טמפרטורה, וניתוח פרופיל צריכה של אפליקציות שונות.

## מבנה הפרויקט
הפרויקט בנוי משני רכיבים מרכזיים:
1. **`MobileApp/`**: אפליקציית מובייל מבוססת React Native המהווה את ממשק המשתמש והמנוע העיקרי לאיסוף הנתונים מהמכשיר.
2. **`website/`**: פרויקט Web מבוסס React המשמש כעמוד נחיתה (Landing Page) ואפשרות לפיתוח עתידי של Dashboard להצגת נתונים.

## דרישות מוקדמות והנחיות התקנה

### סביבת פיתוח
כדי לעבוד על הפרויקט באופן מקומי תצטרכו:
* Node.js (גרסה 22.11 ומעלה)
* Yarn או npm (מומלץ Yarn ל-React Native)
* סביבת פיתוח של React Native מוגדרת (Android Studio / SDK).
* Ruby & Cocoapods (לגרסת iOS, במידה ותיתמך בעתיד).

### הרצת האפליקציה ב-Local
1. הכנסו לתיקיית האפליקציה:
   `cd MobileApp`
2. התקנת תלויות:
   `npm install`
3. הפעלת ה-Metro Bundler:
   `npm run start &`
4. הרצת האפליקציה על אמולטור או מכשיר מחובר:
   `npm run android`

### הרצת אתר האינטרנט
1. הכנסו לתיקיית האתר:
   `cd website`
2. התקנת תלויות:
   `npm install`
3. הפעלת שרת פיתוח:
   `npm run start &`

## הרשאות ושימוש באפליקציה
כדי שהאפליקציה תוכל לגשת לנתונים מתקדמים, היא צריכה הרשאות מיוחדות (`BATTERY_STATS`, `DUMP` וכו'). תהליך קבלת ההרשאות מתבצע בצורה חלקה מהמכשיר בלבד:

1. **הפעלת אפשרויות מפתח**: בהגדרות המכשיר, לחצו 7 פעמים על מספר הבנייה (Build Number) תחת "אודות הטלפון".
2. **הפעלת Wireless Debugging**: בתוך "אפשרויות מפתח", הדליקו את האפשרות "ניפוי שגיאות אלחוטי" (Wireless Debugging).
3. **הגדרת Shizuku**: האפליקציה תנחה אתכם ותפעיל את ממשק ה-Shizuku שישתמש בחיבור האלחוטי כדי לאשר את ההרשאות המתקדמות בצורה מקומית.
4. מרגע זה, האפליקציה אוספת נתונים, שומרת אותם במסד הנתונים המקומי, ומציגה בגרפים.

## מדריך שימוש (למשתמש הקצה)
1. **מסך ראשי**: לאחר סיום תהליך ההתקנה והאישור, המסך הראשי יציג סטטוס סוללה נוכחי: אחוזים, זרם (mA), מתח, טמפרטורה ותחזית זמן פריקה מדויקת בהתבסס על מודל ה-ML.
2. **היסטוריה (History)**: צפו בגרפים המראים את פריקת הסוללה לאורך ימים ושבועות מתוך מסד הנתונים המקומי (SQLite).
3. **צריכת אפליקציות**: מסך המפרט אילו אפליקציות או שירותים (כולל Wakelocks) גרמו לפריקת הסוללה הגדולה ביותר.
4. **התראות (Alerts)**: ניתן להגדיר באפליקציה קבלת התראה כשהסוללה מגיעה לאחוז מסוים או אם המכשיר מתחמם יתר על המידה.
